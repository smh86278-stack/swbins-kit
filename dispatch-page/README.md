# 디스패치 페이지 (휴대폰용)

휴대폰에서 **메일로 일을 맡기는** 보내기 화면입니다. 서버가 없는 정적 페이지 하나(`index.html` + 아이콘 + `manifest.webmanifest`)라
어디에 올려도 됩니다. 페이지 안에는 아무 주소도 들어 있지 않고, 메일 주소·작업 폴더 키·이슈 키 앞부분은 **그 휴대폰 브라우저에만** 저장됩니다.

동작: 할 일을 적고 보내면 `mailto:` 로 **메일 앱이 제목·본문이 채워진 채** 열립니다(예: `#c [T12] 보고서 요약해줘`).
보내기만 누르면 PC 의 메일 게이트웨이(`mail-gateway.py`)가 받아 실행하고 결과를 메일로 회신합니다. 이 페이지는 메일을 직접 보내지도, 읽지도 않습니다.

## 올리는 법 (아무 정적 호스팅이나)

- **GitHub Pages** — 이 폴더만 담은 저장소를 만들고(또는 저장소의 `/docs` 등으로 복사), Settings → Pages 에서 브랜치를 고르면
  `https://<계정>.github.io/<저장소>/` 로 열립니다. 페이지에 비밀값이 없으니 공개 저장소여도 됩니다.
- **사내 웹 서버 · Netlify · Cloudflare Pages · S3 등** — 이 폴더의 파일 네 개를 그대로 올리면 됩니다. HTTPS 면 홈 화면에 앱처럼 추가할 수 있습니다.
- 파일로 바로 열어도(`file://`) 보내기는 되지만, 휴대폰에선 설정 저장·홈 화면 추가가 안 될 수 있습니다.

## 처음 쓸 때

1. 휴대폰으로 페이지를 열고 **설정** — 지시를 받을 내 메일 주소(PC 게이트웨이가 보는 주소, `config.local.json` 의 `mail.user`)를 넣습니다.
2. 작업 폴더 키(`dispatch.workdir_keys` 의 키, 예: `docs`)와 이슈 키 앞부분(`dispatch.issue_prefix`, 예: `PROJ-`)은 PC 설정과 같게 넣습니다.
   이슈 키 앞부분을 비우면 **이슈** 탭이 숨겨집니다.
3. 브라우저 메뉴의 **홈 화면에 추가**로 앱처럼 씁니다.

보낸 메일의 발신 주소가 PC 설정의 `dispatch.allowed_senders` 에 있어야 실행됩니다(비어 있으면 모든 메일을 무시합니다).
태그(`#c` 읽기 · `#cw` 수정 허용)를 PC 에서 바꿨다면 `index.html` 의 `TAG` 도 같게 고칩니다.
