새 일 맡기기

보내면 메일로 PC 게이트웨이에 전달되고, 답은 이 화면에 대화로 옵니다. 폰 메일·디스패치 페이지와 같은 대화입니다.
읽기: 조회·분석만 · 수정 허용: 파일 수정·명령 실행까지(PC 가 실행 전에 확인 메일을 한 번 보냅니다)

메일 계정

지시를 주고받는 내 메일 계정입니다.

작업 폴더 (게이트웨이)

폴더를 고르지 않은 지시가 도는 기본 폴더와, 지시에 @키 로 고르는 폴더들입니다. 키트 설정()의 dispatch 갈래에 저장하고 게이트웨이가 바로 따릅니다.

이 PC 에서 직접 실행

켜면 게이트웨이 PC 없이 이 메신저가 내 메일함에 온 지시(#c 읽기 · #cw 수정 허용)를 이 PC 의 Claude Code 로 실행하고 답을 같은 메일함에 넣습니다. 내 주소에서 온 지시만, 켠 뒤에 온 것만 받습니다. 위 암호 단어를 넣어 두면 그 단어가 붙은 지시만 받습니다(권장). 끄면 하던 일도 멈춥니다.

전용 브라우저 (Playwright)

켜면 수정 허용(#cw) 지시가 웹 사이트 일을 이 PC 의 전용 Chrome 창으로 합니다(Node.js·Chrome 필요, 윈도우는 Edge 도 됨). 쓸 사이트는 로그인 창 열기로 한 번 로그인해 두세요. 로그인·OTP 가 나오거나 결제·삭제·발송 같은 단추 앞에서는 멈추고 묻습니다.

Jira 처리

켜면 'Jira 처리 시작'(#cw /jira 키)을 Jira 읽기 도구로 돌리고, curl·ssh 처럼 밖으로 내보내는 명령은 막습니다. 작업 폴더에 jira 스킬이 있으면 그 스킬을 씁니다. 토큰을 비워 두면 이 PC 의 Claude Code 에 이미 있는 jira MCP 를 씁니다.

Jira 새 티켓 감시

켜면 1분마다 내게 배정된 새 Jira 티켓을 확인합니다. 대화 목록 위 🏃 자리비움이 켜져 있으면 새 티켓마다 '/jira 키' 를 자동으로 처리하고, 꺼져 있으면 실행하지 않고 알림만 남깁니다(나중에 켜도 몰려 돌지 않습니다). 처음 켤 때 이미 있는 티켓은 본 것으로만 적습니다. Jira 주소·토큰·작업 폴더·스킬은 위 'Jira 처리' 칸을 같이 씁니다 — 토큰이 비어 있으면 환경변수 JIRA_TOKEN.
