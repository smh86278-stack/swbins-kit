# 디스패치 대화 사용법 — 윈도우 · 맥

메일로 맡긴 일을 메신저처럼 보는 PC 앱입니다. 메일 계정만 있으면 어느 PC 에서든 같은 대화를 봅니다.
실제로 일을 하는 건 **게이트웨이 PC**(메일 게이트웨이가 도는 PC)이고, 이 앱은 그 메일함을 읽고 씁니다.
게이트웨이 PC 가 없으면 **이 PC 에서 직접 실행**(6절)을 켜서 이 PC 의 Claude Code 가 일하게 할 수도 있습니다.

---

## 1. 받기

| | 윈도우 | 맥 |
|---|---|---|
| 가장 쉬운 방법 | `DispatchChat.exe` 한 파일을 받아 아무 폴더에 둔다 | 이 키트 저장소를 통째로 받아 둔다(zip 또는 `git clone`) |
| 필요한 것 | 없음 | 맥에 기본으로 있는 `python3` (처음 실행 때 "명령어 라인 도구 설치" 창이 뜨면 설치) |
| 설치 과정 | 없음 — 파일을 두는 게 전부 | 없음 |

> 맥용 앱(`DispatchChat.app`)은 맥에서만 만들 수 있습니다. 한 번 만들어 두고 싶으면 **5. 맥에서 앱으로 만들기**.

---

## 2. 처음 열기

**윈도우** — `DispatchChat.exe` 더블클릭.
**맥** — 받은 폴더의 `tools/dispatch-chat/DispatchChat.command` 더블클릭. "확인되지 않은 개발자" 라고 막히면 그 파일을 **우클릭 → 열기** 한 번. 안 열리면 터미널에서 한 번만:

```
chmod +x <받은 폴더>/tools/dispatch-chat/DispatchChat.command
```

앱 창(Edge · 맥은 Edge 나 크롬, 없으면 기본 브라우저)이 열리고 **메일 계정** 창이 뜹니다.

| 칸 | 넣을 것 |
|---|---|
| 메일 주소 | 지시를 주고받을 **내 메일 주소**. 넣고 나면 Gmail·네이버·다음·iCloud 는 서버가 저절로 채워집니다 |
| 로그인 아이디 | 주소와 다를 때만(예: iCloud 는 @ 앞부분만일 수 있음) |
| 비밀번호 | Gmail·iCloud 는 **앱 비밀번호**(2단계 인증 → 앱 비밀번호 만들기). 네이버·다음은 메일 설정에서 IMAP/SMTP 켜기 |
| IMAP / SMTP 서버 | 회사 메일이면 회사 안내대로 |
| Jira 키 앞부분 | 예 `PROJ-` (Jira 탭에서 번호만 넣게) |
| 이슈 명령 | 비우면 `/jira`. 키트 게이트웨이로 보내면 그쪽 `dispatch.issue_command`(기본 `/issue`)와 같게 |
| 보내기 | 보통 "메일 발송". 발송이 막힌 곳이면 "메일함에 넣기" |
| 암호 단어 | **회사 밖 메일**(Gmail 등)로 지시할 때만 — 게이트웨이 담당자에게 받은 단어. 회사 메일이면 비워 둠 |

"연결 확인 후 저장" 을 누르면 실제로 메일함에 들어가 봐서 되면 저장합니다. 비밀번호는 윈도우는 DPAPI(그 PC 의 내 계정만 풀 수 있음), 맥은 키체인에 들어갑니다 — 맥에서 키체인 허용 창이 뜨면 **항상 허용**.

> 키트 저장소 안(게이트웨이 PC — 허브 '💬 대화')에서 열면 계정 창이 안 뜹니다. 키트 공통 설정(`config.local.json` 의 `mail` · `dispatch`)의
> 계정을 그대로 쓰기 때문입니다(화면 위에 "키트 설정 계정(이 PC 게이트웨이)"). 이슈 칸은 `dispatch.issue_prefix`·`issue_command` 를 따릅니다.

## 3. 쓰기

### 새 지시
왼쪽 **＋ 새 지시** → 할 일을 적고 보내기(Ctrl+Enter).
- **읽기 / 수정 허용**: 읽기는 보고·조사만, 수정 허용은 파일을 고치는 일까지. 파일을 바꾸는 일이면 "수정 허용".
- **작업 폴더** 칩: 게이트웨이 PC 의 어느 폴더에서 일할지. 비우면 기본 폴더.
- 보내면 목록 맨 위에 "보냄" 으로 올라오고, 게이트웨이가 받으면 "작업 중", 답이 오면 번호(**T12** 같은)가 붙으며 "완료".

### 이어서 말하기
대화방 아래 입력칸에 적고 보내면 같은 대화(같은 세션)에 이어집니다. Claude 가 그 전 맥락을 기억합니다.

### 답할 차례(선택지)
Claude 가 물어보면 말풍선 아래 **체크박스/라디오**가 뜹니다. 고르고 "답 보내기". 덧붙일 말이 있으면 아래 칸에.

### 멈춤
돌고 있는 일을 끊으려면 **멈춤**. 하던 일은 중간에 끊기고 "멈췄습니다" 로 돌아옵니다.

### 급건 · 저장해 두는 답
- **🔥 급건** — 대화 위쪽 단추로 표시하면 목록 맨 위에 고정되고 눈에 띕니다. 목록 위 🔥 로 급건만 볼 수 있습니다.
- **📝** — 입력칸 옆 단추. 자주 쓰는 말을 골라 넣습니다. 지금 입력칸의 글을 저장하거나 × 로 뺄 수 있습니다.
- 둘 다 이 PC 에만 남습니다(`%LOCALAPPDATA%\DispatchChat\urgent.json` · `snippets.json`) — 메일·다른 PC 와 나누지 않습니다.

### 실패했을 때
대화가 **오류**로 끝나면 아래에 카드가 뜹니다.
- **🔁 다시 실행** — 실패한 지시를 같은 대화 번호·폴더·권한으로 그대로 다시 돌립니다(시간 초과처럼 중간에 끊긴 일도). 폰 메일에서 `다시 실행` 이라고 답해도 같습니다.
- **📋 실패 기록 복사** — 지시·실패 내용·시각·작업 번호를 문의 글에 붙여 넣기 좋게 복사합니다.
- **✉ 문의** — `company.json` 에 `support_email` 을 넣어 두면 나타나고, 그 주소로 기록을 담은 메일을 엽니다.

### Jira
**Jira** 탭(키트 설정이면 **이슈**)에 티켓 번호만 넣으면(`123` → `PROJ-123`) 그 건을 처리하라는 지시(`#cw /jira PROJ-123` — 이슈 명령)가 갑니다.
키트 설정에서는 `dispatch.issue_prefix` 가 있어야 칸이 보입니다.

### 목록 정리
대화방의 🗑 은 **이 PC 목록에서만** 숨깁니다. 메일은 그대로입니다.
목록 위 🧹 는 **대화 전체**를 같은 방식으로 숨깁니다 — 일하는 중이거나 확인을 기다리는 대화는 남고, 지운 대화에 새 글이 오면 다시 보입니다.
잘못 눌렀으면 10초 안에 🧹 를 한 번 더 누르면 되돌아갑니다.

## 4. 진행 상황 카드 (게이트웨이 PC · 이 PC 에서 직접 실행할 때)

게이트웨이 PC 의 메신저나 **이 PC 에서 직접 실행**을 켠 메신저에서는 **작업 중인 대화방에 진행 카드**가 뜹니다 — 2초마다 갱신.

- `● Bash 작업 트리 보기` → 끝나면 `✓`, 실패하면 `✕`
- 💬 Claude 가 중간에 하는 말, `할 일 2/5 — …` 할 일 목록 진행
- 몇 단계째, 몇 초째
- **단계를 누르면** 그 도구에 넘긴 전체 입력(명령 전문, 고친 내용은 `-`/`+` 줄)과 결과 출력이 펼쳐집니다. 펼쳐 둔 건 갱신돼도 유지.

다른 PC·맥에서는 진행 기록이 없어 "작업 중" 까지만 보이고, 결과는 회신으로 받습니다.

**이 PC 에서 직접 실행**할 때 폰(또는 메일 앱)에서 맡긴 일이 **3분 넘게** 걸리면 중간에 **진행 메일 한 통**(`진행 중 · 5분째 — 지금 하는 일 · 할 일 2/5`)이 옵니다 —
일 하나에 딱 한 번이라 메일함이 차지 않습니다(키트 게이트웨이는 진행 메일을 보내지 않습니다 — 진행 카드로 봅니다). 폰 페이지·이 화면에서는 말풍선이 아니라 "작업 중" 아래 **작은 회색 줄**로 보이고, 답(완료·안 읽음)으로 세지 않으며, 최종 답이 오면 사라집니다.

## 5. 맥에서 앱으로 만들기 (선택)

`.command` 대신 더블클릭 앱을 원하면 맥에서 한 번:

```
cd <받은 폴더>/tools/dispatch-chat
python3 -m pip install pyinstaller
python3 build.py
```

`tools/dispatch-chat/dist/DispatchChat.app` 이 생깁니다. 응용 프로그램 폴더로 옮겨 쓰면 됩니다(처음 한 번 우클릭 → 열기). 윈도우 exe 도 같은 방법(`python build.py`)으로 만듭니다.

회사 값(메일 서버·Jira 접두어·Jira 주소)을 처음부터 채워 두고 싶으면 `company.example.json` 을 `company.json` 으로 복사해 채운 뒤 만드세요 — 앱에 같이 들어갑니다.
회사에서 나눠 준 `company.json` 이 있으면 `tools/dispatch-chat/` 폴더에 넣기만 하면 됩니다 — `.command` 로 띄울 때도 그 값으로 시작합니다(git 에는 안 올라감).

**맥에서 직접 실행·브라우저·Jira 를 쓸 때 필요한 것** (Homebrew 기준 — 이미 있으면 건너뜀)

```
curl -fsSL https://claude.ai/install.sh | bash && claude   # Claude Code 설치 + 한 번 로그인
brew install node                                        # 전용 브라우저(npx) — nvm·volta 로 깐 것도 찾습니다
brew install uv                                          # Jira 토큰을 메신저에 넣을 때(uvx)
```

Chrome(없으면 Edge)이 있어야 전용 브라우저를 켤 수 있습니다. Jira 토큰은 맥 키체인에 `DispatchChat` / `jira` 항목으로 들어갑니다.

## 6. 이 PC 에서 직접 실행 (선택 — 기본 꺼짐)

게이트웨이 PC 없이 **이 PC 가 직접** 지시를 받아 일하게 합니다. 폰에서 보낸 지시도 이 PC 가 받아 처리합니다.

**필요한 것** — 이 PC 에 [Claude Code](https://docs.anthropic.com/claude-code) 설치, 터미널에서 `claude` 를 한 번 실행해 로그인. 없으면 스위치가 잠기고 안내만 나옵니다.

**켜는 법**
1. ⚙ → 아래쪽 **이 PC 에서 직접 실행**.
2. **기본 작업 폴더**(지시를 실행할 폴더)를 확인하고, 필요하면 **다른 작업 폴더**를 `키=폴더` 로 한 줄씩(지시에 `@키` 로 고름).
   사람마다 달라도 됩니다(예: `web=C:\work\web`). 새 대화의 폴더 칩 옆 **＋** 로도 이 칸이 열립니다.
   게이트웨이 PC(키트 설정)의 메신저는 이 칸 대신 위쪽 **작업 폴더 (게이트웨이)** 칸에서 정합니다(`config.local.json` 의 `dispatch` 에 저장 —
   기본 폴더를 바꾸면 회사 모드 폴더는 옛 기본 폴더로 남깁니다).
3. 스위치를 켭니다. 켠 **그 시각 이후에** 온 지시만 받습니다. 위쪽 상태 줄에 "· 이 PC 에서 실행" 이 붙습니다.
4. 폰에서 쓰려면 폰 페이지·폰 메일 앱이 **이 메신저와 같은 계정에서 '나에게'** 보내야 합니다.

**안전 규칙**
- **내 주소에서 온 지시만** 실행합니다. 남이 보낸 메일은 제목이 `#c` 로 시작해도 실행하지 않습니다.
- **암호 단어**(계정 칸)를 넣어 두면 그 단어가 붙은 지시만 받습니다 — 이 앱과 폰 페이지는 자동으로 붙입니다. 내 주소를 사칭한 메일을 막으려면 넣어 두세요.
- 수정 허용(`#cw`) 새 지시는 실행 전에 "실행할까요?" 를 한 번 묻습니다 — **실행**을 골라야 돌아갑니다(60분 지나면 취소).
- 한 번 처리한 메일은 다시 실행하지 않습니다. 끄면 하던 일·기다리던 일도 멈춥니다.
- **게이트웨이 PC 에서는 켤 수 없습니다**(키트 설정의 계정을 쓰거나 이 저장소의 키트 게이트웨이가 켜져 있으면 스위치가 잠기고 이유가 나옴).
  다른 PC 의 게이트웨이가 같은 메일함을 읽고 있으면 같은 지시가 두 번 돌 수 있으니 **켜지 마세요** — 켠 뒤 그쪽 회신이 보이면 이 PC 쪽이 스스로 꺼지고 화면 위에 알립니다.

**되는 것** — 이어서 말하기, 선택지 답, 멈춤, 수정 허용 확인, 폰 지시 접수 표시, 진행 카드(4절), 폰 사진.
**안 되는 것(게이트웨이에만 있음)** — 다른 주소(iCloud 등)에서 오는 지시, Gmail 따로 읽기·스팸함 보기, 폰 주소로 회신 사본.

**전용 브라우저 (따로 켬 — 기본 꺼짐)** — 수정 허용(`#cw`) 지시가 웹 사이트 일(조회·입력)을 이 PC 의 전용 Chrome 창으로 합니다.
- 필요한 것: Node.js(npx) · Chrome(윈도우는 Edge 도 됨). 없으면 스위치가 잠기고 이유가 마우스를 올리면 나옵니다.
- 켠 뒤 **로그인 창 열기** → 열린 창에서 쓸 사이트에 한 번 로그인해 둡니다. 창은 닫아도 되고, 열어 두면 지시가 그 창을 씁니다.
- 로그인·OTP 화면이 나오거나 결제·삭제·발송 같은 단추 앞에서는 멈추고 선택지로 묻습니다.

**Jira 처리 (따로 켬 — 기본 꺼짐)** — Jira 탭의 **처리 시작**(`#cw /jira 키`)을 Jira 도구로 돌리고, curl·ssh 처럼 밖으로 내보내는 명령은 막습니다.
- **Jira 주소**와 **개인 토큰**을 넣으면 이 앱이 Jira 읽기 도구를 붙입니다(uv 필요). 토큰을 비우면 이 PC 의 Claude Code 에 이미 등록된 `jira` MCP 를 씁니다.
- **Jira 작업 폴더**를 넣으면 Jira 지시는 그 폴더에서 돕니다. 그 폴더에 **Jira 스킬 이름**(비우면 `jira`)의 스킬이 있으면 스킬대로, 없으면 이슈를 읽고 고칠 방향을 먼저 묻습니다.
- 스킬이 curl 로 Jira 를 읽는다면 **curl·ssh 허용**을 켭니다(기본은 막음).

**Jira 새 티켓 감시 · 🏃 자리비움 (따로 켬 — 기본 꺼짐)** — 1분마다 **내게 배정된 새 Jira 티켓**을 봅니다. 위 Jira 처리 칸(주소·토큰·작업 폴더·스킬)을 같이 씁니다.
- 켜면 대화 목록 위에 **🏃 자리비움** 단추가 생깁니다. **켜 두면** 새 티켓마다 `/jira 키` 를 자동으로 처리하고 결과가 대화로 옵니다(한 번에 최대 3건).
  **꺼 두면** 실행하지 않고 "새 티켓 N건 — 직접 처리" 알림만 남습니다(나중에 켜도 몰려 돌지 않음).
- 처음 켤 때 이미 있는 티켓은 본 것으로만 적습니다. 자리비움 중 자동 처리는 **이 PC 에서 직접 실행**이 켜져 있어야 합니다.
- 빼는 규칙(발생환경 계정 · 연결 이슈 제목, 정규식)은 `company.json` 에 미리 넣어 둘 수 있고, ⚙ 의 감시 칸에서 바꿀 수 있습니다.
- **게이트웨이 PC(키트 설정)에서는 켤 수 없습니다** — 그 PC 의 새 이슈는 키트의 `jira-watch.py`(`config.local.json` 의 `jira` 갈래)가
  "지금 처리할까요?" 를 대화로 묻고 처리합니다. 같은 메일함을 쓰는 다른 PC 에서 켤 때도 키트 감시와 겹치지 않게 하세요.

**질문 답 기한** — Claude 가 선택지로 물은 뒤 **하루** 답이 없으면 질문이 닫혔다는 알림이 오고 '답할 것' 에서 빠집니다 — 늦게 답해도 그대로 이어집니다.

## 7. 막혔을 때

| 증상 | 볼 것 |
|---|---|
| 위 점이 빨갛고 "메일함을 읽지 못했습니다" | 비밀번호(앱 비밀번호인지) · IMAP 이 켜져 있는지 · 회사망이면 서버 주소. ⚙ 에서 다시 저장 |
| 보냈는데 "작업 중" 이 안 됨 | 게이트웨이 PC 가 켜져 있고 그 메일함을 읽는지. 회사 밖 메일이면 **암호 단어**가 게이트웨이와 같은지, 스팸함에 안 갔는지 |
| 맥: "윈도우에서 만든 설정입니다" | 윈도우의 설정 파일을 복사해 온 경우 — ⚙ 에서 계정을 다시 넣으면 됨 |
| 창이 안 열리고 서버만 뜸 | 브라우저에서 직접 `http://127.0.0.1:8620/` |
| 8620 포트가 이미 쓰임 | 환경변수 `DISPATCH_CHAT_PORT=8621` 로 띄우기 |
| 직접 실행 스위치가 잠김 | 옆 안내대로 — Claude Code 설치·로그인, 메일 계정 먼저, 게이트웨이 PC(키트 설정·키트 게이트웨이 켜짐)가 아닌지 |
| 브라우저 지시가 "로그인 필요" 로 멈춤 | ⚙ → **로그인 창 열기** 에서 그 사이트에 로그인한 뒤 "이어서" 라고 답하기 |
| Jira 지시가 이슈를 못 읽음 | Jira 주소·토큰, uv 설치 여부. 토큰을 비웠다면 이 PC 의 Claude Code 에 `jira` MCP 가 있는지(`claude mcp list`) |
| 직접 실행을 켰는데 안 돎 | 지시가 **내 주소에서** 왔는지, 암호 단어가 맞는지, 켠 **뒤에** 보냈는지. 화면 위 띠의 이유 · 로그의 `[실행]` 줄 |
| 로그 | 윈도우 `%LOCALAPPDATA%\DispatchChat\chat.log` · 맥 `~/Library/Application Support/DispatchChat/chat.log` |

설정 파일 위치 — 윈도우 `%APPDATA%\DispatchChat\config.json`, 맥 `~/Library/Application Support/DispatchChat/config.json`. 지우면 처음 상태로 돌아갑니다.
