나만의 자동화 만들기

반복하는 일을 한 번 보여 주거나 말로 부탁하면, 다음부터 그대로 합니다.

보여 주기웹에서 한 번 해 보이면 그대로 따라 합니다
Chrome 이 열리면 평소대로 조작하고 창을 닫으면 저장됩니다. 비밀번호 칸의 값은 파일에 남지 않고 이 PC 비밀 보관함으로 옮겨집니다.
말로 부탁하기녹화로 안 되는 일(프로그램 조작·조건·알림)은 AI 에게
누르면 가 이 PC 에서 바로 만듭니다. 진행은 아래 실행 기록에서, 다 되면 자동화 목록에 나타납니다. 누르면 대화로 보냅니다. Claude 가 만든 뒤 스스로 시험하고, 안 되면 고쳐서 결과를 대화로 알립니다(메일 보내기·제출은 시험 때 건너뜀). 다 되면 자동화 목록에 나타납니다.
디스패치 대화(설정 dispatch.enabled)를 켜면 여기서 바로 맡길 수 있습니다. 지금은 위 단추로 부탁 글을 복사해 이 PC 의 Claude Code 에 붙여 넣으세요.

    내 앱

    이 PC 에서만 도는 앱을 AI 와 함께 만듭니다 — 설계서 → 만들기 → 자동 검사 → 고치기. 앱마다 격리되어 허브·다른 앱의 데이터에 손대지 못하고, 바깥 주소로 자료를 내보내지 못합니다.

    새 앱템플릿을 고르고 무엇을 만들지 적으면 AI 가 설계서부터 씁니다
    비워 두면 템플릿 그대로 만듭니다. 설계서를 확인한 뒤 「이대로 만들기」를 누르세요.
    받은 앱 zip 이 있으면 — 위에 앱 이름·주소 이름을 적고
    나만의 앱 서버가 꺼져 있습니다(설정 apps.enabled · 포트 apps.port).
