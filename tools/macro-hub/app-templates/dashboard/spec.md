# 설계서 — 기록 대시보드 (템플릿 기본)

## 목적
매일 생기는 숫자(매출·지출·처리 건수)를 적어 두고 한눈에 흐름을 본다.

## 화면
- 위: 요약 숫자 4개(이번 달 합계 + 지난달 대비 ▲▼% · 지난달 합계 · 전체 기록 수 · 분류 수)
- 입력 줄: 날짜 · 분류(전에 쓴 분류 추천) · 숫자 · 메모 · 기록
- 차트: 최근 30일 날짜별 추이(선) · 분류별 비율(도넛)
- 아래: 최근 기록 20개 표(지우기)

## 데이터
entries(id, day YYYY-MM-DD, category, amount, note)

## 동작
- 기록 → 요약·차트·표가 바로 다시 그려진다
- ✕ → 그 기록을 지운다

## 완료 기준
- 기록을 하나 넣으면 최근 기록 표에 보인다
- 요약 '전체 기록' 이 1건 늘어난다
- 차트 두 개가 그려진다(canvas)
