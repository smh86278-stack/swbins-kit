# 설계서 — 별 모으기 (템플릿 기본)

## 목적
쉬는 시간 1~2분짜리 아케이드 게임.

## 화면
- 시작: 제목 · 최고 점수 · '스페이스·클릭으로 시작'
- 플레이: 아래쪽 막대(나) · 위에서 떨어지는 돌(회색)·별(노랑) · 왼쪽 위 점수 · 오른쪽 위 레벨
- 끝: 점수 · 새 최고 점수 표시 · 다시 하기

## 데이터
scores(id, score, at) — 최고 점수는 MAX(score)

## 동작
- ← → 또는 마우스로 좌우 이동, P 일시정지
- 별에 닿으면 +10, 돌에 닿으면 끝
- 8초마다 빨라지고 더 자주 떨어진다

## 완료 기준
- 게임이 뜬다(canvas, window.game)
- 시작하면 플레이 장면으로 넘어간다
