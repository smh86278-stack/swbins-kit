# 설계서 — 텍스트 손질 (템플릿 기본)

## 목적
메일·엑셀·시스템에서 복사한 글을 매번 손으로 다듬는 일을 한 번에.

## 화면
- 위: 규칙 체크칸(앞뒤 공백 · 연속 공백 · 빈 줄 · 중복 줄 · 정렬 · 번호 · 한 줄로 · 표 미리보기)
- 왼쪽: 원본(줄·글자 수) · 오른쪽: 결과(줄 수·중복 없는 줄 수, 복사 단추)
- 아래: 표 미리보기(첫 줄은 머리글, 50줄까지)

## 데이터
없음 — 저장하지 않는다(권한 없음)

## 동작
- 붙여 넣거나 체크를 바꾸면 결과가 바로 바뀐다(위 규칙 순서대로 적용)
- 복사 → 클립보드

## 완료 기준
- 중복 줄을 넣고 '중복 줄 지우기' 를 켜면 결과 줄 수가 준다
- 번호 붙이기를 켜면 '1. ' 로 시작한다
