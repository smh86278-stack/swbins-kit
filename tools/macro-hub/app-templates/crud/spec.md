# 설계서 — 목록 관리 (템플릿 기본)

## 목적
반복해서 생기는 업무 항목(요청·거래처·재고 등)을 한곳에 적고 상태별로 본다.

## 화면
- 위: 제목·안내 · 입력 칸(항목 이름 · 상태 · 메모 · 추가)
- 가운데: 찾기 칸 · 상태 거르기 단추(전체·할 일·진행 중·완료 + 개수)
- 아래: 표(항목 · 상태 · 메모 · 고친 때 · 고치기/지우기)

## 데이터
items(id, title, status[todo|doing|done], memo, created, updated)

## 동작
- 추가 → 표 맨 위(진행 중 → 할 일 → 완료 순)에 나타난다
- ✎ → 같은 입력 칸이 위에 열려 고친다 · ✕ → 확인 뒤 지운다
- 찾기는 이름·메모에서, 상태 단추는 그 상태만

## 완료 기준
- 항목을 추가하면 표에 보인다
- 찾기 칸에 글자를 넣으면 맞는 항목만 남는다
- 상태 단추에 개수가 맞게 나온다
